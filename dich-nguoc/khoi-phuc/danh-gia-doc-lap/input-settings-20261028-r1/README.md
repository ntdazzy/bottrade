# Khai báo cài đặt đầu vào

Đã lấy tên và giá trị mặc định từ snapshot `.set` đã đọc trong MT5 riêng,
sinh khai báo `input` MQL5 và biên dịch bằng MetaEditor riêng:

| Bot | Khai báo thực | Biên dịch |
|---|---:|---|
| Bot 1 | 71 | 0 lỗi / 0 cảnh báo |
| Bot 3 | 79 | 0 lỗi / 0 cảnh báo |

Các menu đã biết vẫn giữ đúng giá trị số đã đo: tốc độ chạy, bộ lọc giả,
cách tính rủi ro và tần suất. Bước này mới xác nhận tên/kiểu/giá trị mặc
định có thể biên dịch; chưa xác nhận mọi tác dụng của từng cài đặt khi EA
chạy. Không được dùng nó làm bằng chứng hoàn thành menu hoặc toàn bot.
